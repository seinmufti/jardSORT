# JardSort

Plan cuts for 600 cm profile rods from frame width × height measurements (React + Vite).

```bash
npm install
npm run dev
```

Open [http://localhost:5175/](http://localhost:5175/) (designated dev port).

On your phone (same Wi‑Fi), use the **Network** URL from `npm run dev` (e.g. `http://192.168.x.x:5175/`). Allow Node through Windows Firewall if the page never loads.

```bash
npm test
```
